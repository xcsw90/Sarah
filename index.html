Vehicle Forensics · Research

EyeWolf — Virtual Vehicle Write Blocker

A Python tool (eyewolf.py) that acts as a software write blocker for vehicle CAN networks, so investigators can read data from a car without altering it. Built and tested in a virtual lab using vcan and can-utils.
